# Python Beginner Practice

A collection of beginner-friendly Python programs created while learning
the fundamentals of Python programming.

## Topics Covered

- Variables
- User Input and Output
- Conditional Statements
- Loops
- Functions
- Lists
- Basic Problem Solving

## Projects

### 1. Personal Information
A simple program that collects and displays user information.

### 2. Simple Calculator
Performs basic arithmetic operations using functions.

### 3. Even or Odd Checker
Determines whether a number is even or odd.

### 4. Number Guessing Game
A simple interactive guessing game using a while loop.

### 5. Student Grade Calculator
Calculates a student's average and assigns a grade.

### 6. List Statistics
Calculates the total, average, highest, and lowest values in a list.

### 7. To-Do List
A command-line application for adding, viewing, and removing tasks.

### 8. Expense Tracker
A simple command-line application for recording and viewing expenses.

## How to Run

Make sure Python is installed on your system.

Open the repository in VS Code and run any program using:

```bash
python filename.py
